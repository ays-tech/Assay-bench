# Getting help

- **Usage questions and ideas**: open a [GitHub Discussion](https://github.com/ays-tech/Assay-bench/discussions)
  if it is enabled, otherwise a regular issue labelled `question`.
- **Something looks broken**: run `node bin/assay.js probe` first (it confirms Assay reads
  your gateway's API shapes), then open a [bug report](https://github.com/ays-tech/Assay-bench/issues/new?template=bug_report.yml).
- **Security problem**: do not open an issue. See [SECURITY.md](SECURITY.md).
- **Problems with the gateway itself** (billing disputes, outages, account issues): contact
  the gateway provider. Assay only measures, it cannot fix them.

Before posting, please read the [README](README.md) and check existing issues. Remove
API keys and anything private from logs and reports first.
