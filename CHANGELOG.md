# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project aims to follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html) once it reaches 1.0.

## [Unreleased]

### Added
- Community health files: Code of Conduct, Contributing guide, Security policy, Support
  guide, issue and pull request templates, and a CI workflow.

## [0.1.0]

### Added
- Audit: billing, model identity, token counts, API compatibility and latency checks with a
  fineness score out of 1000.
- Bench: replay your own prompts against cheaper models, graded, with cost per correct answer.
- Dashboard, savings estimator, single-file `scorecard.html` export and offline `assay demo`
  with a fault-injecting mock gateway.
